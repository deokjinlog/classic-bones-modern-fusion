# 시나리오 샘플 01 — 로코 팩 v0로 생성

> **증명하려는 것**: 유저가 소재·주연만 던지면(입력), `packs/romcom.md`의 슬롯·비트·톤이 나머지를 몰아 시나리오가 나온다. 그리고 팩의 ⑥루브릭으로 자동 채점된다.

## 입력 (유저가 채운 슬롯)

- **관계 역학**: 앙숙 → 연인
- **소재**: 층간소음
- **주연 A**: 이서준(28) · 재택 일러스트레이터 · 예민, 직접 말 못 하고 쪽지로 항의(결점=솔직 못함)
- **주연 B**: 강도현(30) · 위층 · 새벽 홈트 피트니스 유튜버 · 무신경·직진·해맑음(A와 정반대)
- **배경**: 현대 오피스텔

## 생성 결과 (팩의 7비트를 따라)

1. **Meet-cute** — 천장 쿵쿵에 폭발한 서준, 빗자루로 천장 치다 못 참고 올라가 벨. 문 열자 땀범벅 도현: "아, 혹시 아래층? 저 완전 팬인데요, 쪽지 필체 예뻐서 캡처해뒀어요." (최악 + 엉뚱)
2. **끌림 + 저항** — 도현이 사과한다며 반찬·소음측정기 들고 자꾸 찾아옴. 서준은 귀찮은데 자꾸 신경 쓰인다. "이 무신경한 인간이 대체 왜."
3. **가까워짐** — 도현이 서준 그림을 우연히 보고 채널 썸네일 의뢰. 티격태격 밤샘 협업. (개그: 도현이 근육 자랑 포즈를 "레퍼런스"라며 자처)
4. **중간점(자각)** — 마감날 쓰러질 뻔한 서준을 도현이 챙김. 서준: "어… 나 왜 이 인간이 안 싫지?"
5. **오해 → 2막 이별** — 도현이 "아래층 그분 덕분" 브이로그를 올림. 서준은 자기 그림·사생활을 콘텐츠로 팔았다 오해, 폭발. "내가 네 콘텐츠야?" 관계 단절.
6. **그랜드 제스처(감동 전환)** — 도현이 영상 다 내리고 고백: "제가 밤에 시끄러웠던 건 잠이 안 와서였어요. 아래층에서 그림 그리는 불빛 보이면 안심돼서, 그쪽 따라 깨어있었어요."
7. **해피엔딩** — 서준이 쪽지 대신 직접 위층 문을 두드린다. "…오늘은 안 시끄러웠는데요." 처음으로 웃으며.

## 루브릭 자동 채점 (팩 ⑥)

| 항목 | 통과 | 근거 |
|---|---|---|
| Meet-cute | ✅ | 빗자루 항의 → "팬이에요" |
| 관계 역학 명확 | ✅ | 앙숙 → 연인 |
| 코미디 요소 | ✅ | 무신경 vs 예민 · 근육 레퍼런스 |
| 중간 위기(2막 이별) | ✅ | 브이로그 콘텐츠 오해 |
| 그랜드 제스처(감동) | ✅ | 그림 내리고 "불빛 보면 안심" 고백 |
| 현대 배경 | ✅ | 오피스텔·유튜버·재택 |

**6/6 통과** → "웃긴 + 감동 + 현대" 로코 성립. 팩이 실제로 시나리오를 몰아냈다.

## "쭉쭉" = 소재만 바꾸면 무한 (design-explosion의 30처럼)

같은 팩, 관계역학·소재만 교체:
- 가짜연애 + 회사 → 상사와 가짜 연인 계약
- 친구→연인 + 게임 → 10년 길드원, 오프 첫 만남
- 재회 + 카페 → 첫사랑이 옆 가게 사장으로

→ **팩 1개가 소재 N개 × 관계역학 4개 = 시나리오 무한.** 데이터(AO3 인기 관계·Goodreads 리뷰)로 "어떤 조합이 먹히나"를 접지하는 게 다음 단계.
