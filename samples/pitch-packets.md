# 피칭 패킷 예시 — 도구 실출력

`src/match.py`가 각 세팅의 1등 뼈대를 고르고, 그 뼈대를 세팅 재료로 융합한 결과. 서로 다른 세팅×뼈대로 도구의 범위를 보여준다.

---

## ① 우주기업/정거장 × 원정·탐색 (오디세이형) — 최고 검증 62
```
프리미스 : 파산 직전 우주 운송선. 선장은 회사의 마지막 미션—외행성 궤도의 버려진 화물을
           회수하면 빚이 청산된다—을 받고 항행에 나선다. 항로마다 사이렌 같은 조난 신호,
           정거장의 유혹, 죽은 동료의 잔해가 기다리고, 화물의 정체는 회사가 숨긴 것이었다.
           귀환했을 땐, 돌아갈 항구가 이미 팔린 뒤다.
comp    : 오디세이 meets 딥스페이스 화물선
로그라인 : 빚을 갚으러 우주 험로를 건너는 선장이, 회수할 화물이 회사의 거짓임을 알고도 귀향을 택한다.
근거   : 검증 62(freq 14 + 캐논 6·최상위) · 신선 0.5 · 양립 3/3(G16 여정·G18 화물·G9 은폐) · 우주기업 1등
뼈대     : 원정·탐색 — 부름→여정→시련→도달→귀환·대가
```

## ② 대학원 연구실 × 죄와 벌 (도스토옙스키형)
```
프리미스 : 등록금과 논문 압박에 짓눌린 박사과정생이, 자기 성과를 가로챈 지도교수의 데이터를
           몰래 조작해 되갚는다. "이건 정의야"라는 합리화. 하지만 조작이 논문을 통과시킨
           순간부터 양심이 그를 갉아먹고, 후배가 그 조작으로 실험을 반복하다 사고를 당하자 —
           그는 스스로를 고발할지 무너진다.
comp    : 죄와 벌 meets 대학원 실험실
로그라인 : 착취당한 대학원생의 '정당한' 데이터 조작이, 양심에 잠식돼 그를 자백으로 내몬다.
근거   : 검증 29(freq 5 + 캐논 3) · 신선 0.7 · 양립 2/2(G8 성과 가로채기·G1 사제 서열) · 대학원 1등
뼈대     : 죄와 벌 — 합리화→범죄→압박→잠식→자백
```

## ③ 프로게임단 × 찬탈복수 (햄릿형) — 같은 뼈대의 다른 세팅
```
프리미스 : 팀을 창단한 전설의 주장이 '은퇴'로 물러난 뒤, 그 자리를 꿰찬 신임 에이스가 팀을
           독식한다. 주장의 연습생 동생이 뒤늦게 로스터에 들고, 삭제됐어야 할 스크림 로그에서
           형의 은퇴가 감독의 조작이었음을 안다. 폭로하면 팀은 해체·자신은 방출 — 망설이는
           사이 진실을 아는 코치가 잘려나가고, 결승 무대에서 모든 게 터진다.
comp    : 햄릿 meets e스포츠
로그라인 : 형의 주전 자리를 뺏은 에이스에게 복수하려는 신인이, 팀을 죽이지 않고 진실을 밝힐 길을 찾다 그 망설임이 팀을 무너뜨린다.
근거   : 검증 33(freq 1 + 캐논 4) · 신선 0.75 · 양립 2/2(G3 주전 자리·G9 조작 은폐) · 프로게임단 1등
뼈대     : 찬탈복수 — 찬탈→진실→망설임→곁가지 죽음→공멸
```
> ③은 「센터」(햄릿×아이돌)와 **같은 뼈대**가 다른 세팅으로 이식된 예 — 검증된 구조가 여러 무대에 옮겨짐을 보여준다.
