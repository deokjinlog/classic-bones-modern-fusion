# 시나리오 샘플 02 — 로코 팩으로 생성 (친구→연인)

> 입력(소재·주연)만 던지면 팩 슬롯·비트가 나머지를 몰아 시나리오가 나오는지 증명. 샘플01(앙숙)과 다른 관계역학(친구→연인)으로.

## 입력 (유저가 채운 슬롯)

- **관계 역학**: 친구 → 연인
- **소재**: 스타트업 공동창업
- **주연 A**: 김하늘(29) · 개발자 · 감정 서툰 T · 준을 오래 좋아했지만 "말하면 다 잃어"라 못 함
- **주연 B**: 이준(29) · 기획자 · 밝고 사교적 F · 연애는 잘하는데 정작 하늘 마음엔 눈치 없음
- **배경**: 현대, 공유오피스 스타트업

## 생성 결과 (팩 7비트)

1. **Meet-cute(회상)** — 대학 발표 날 얼어붙은 하늘을, 처음 본 준이 즉흥으로 "제 공동발표자입니다" 하고 끼어들어 살림. 그게 10년 팀플의 시작.
2. **끌림 + 저항** — 하늘은 오래전부터 준을 좋아하지만 *"친구인데, 동업자인데, 말하는 순간 이 관계가 끝나"* — 벽.
3. **가까워짐** — 창업 밤샘, 티키타카, 라면 나눠먹고 서로 챙김. 감질나게 가까워지는데 선은 안 넘음.
4. **중간점(자각)** — 준이 무심코 *"야, 넌 내가 세상에서 제일 아끼는 사람이야."* — 하늘 심장 쿵. 근데 준은 그냥 친구 말투.
5. **2막 위기(삼각+오해)** — 투자자가 딸 소개팅을 조건처럼 내밀고, 사업 위해 나가는 준. 하늘은 질투 + *"우린 그냥 동업자잖아"*라고 준이 못 박았다 오해 → 냉랭.
6. **그랜드 제스처** — 데모데이 무대. 준이 발표 끝에 10년 전 그 대학 발표 사진을 띄운다. *"제 공동창업자이자… 제가 10년 동안 못 본 척한 사람입니다."* (소개팅은 이미 뛰쳐나온 뒤)
7. **해피엔딩** — 객석의 하늘, 처음으로 마이크에 대고: *"…나도 10년."* 웃으며.

## 루브릭 체크 (팩 ⑥)

| 항목 | 통과 | 근거 |
|---|---|---|
| Meet-cute | ✅ | 대학 발표 즉흥 커버 |
| 관계 역학 명확 | ✅ | 친구 → 연인 |
| 코미디 요소 | ✅ | T/F 티키타카 · 눈치 없는 준 |
| 2막 위기 | ✅ | 삼각(소개팅) + 오해 |
| 그랜드 제스처 | ✅ | 데모데이 무대 고백 |
| 현대 배경 | ✅ | 스타트업 공유오피스 |

**6/6 통과** — 팩이 실제로 시나리오를 몰아냄.
