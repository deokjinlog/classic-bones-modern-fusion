# classic-bones-modern-fusion

> **수백 년 검증된 고전 이야기의 뼈대**를, 아직 아무도 안 넣어본 **현대 세팅**에 이식해 —
> 신선하되 말 되는 이야기 프리미스를 **"진짜 덜 쓰였다"는 실데이터 영수증**과 함께 뽑아준다.

design-explosion의 **스토리판**. "AI가 이야기를 쓴다"가 아니라, 실제 이야기 수만 편을 **세어서** 조준하는 분석 도구.
산출 = **Claude Code 스킬 + 배포 아티팩트 쇼케이스** (무서버).

---

## 3층 구조
| 층 | 뭐냐 | 출처 |
|---|---|---|
| **뼈대 (skeleton)** | 이야기의 구조 = 엔진 + 역할 + 턴 (예: 찬탈복수 = 햄릿형) | WikiPlots 플롯에서 추출 |
| **스키마 (schema)** | 뼈대가 *요구하는 구조 조건*의 공통 어휘 (~25칸) | WikiPlots 요구조건 군집으로 **도출** |
| **세팅 (setting)** | 이식할 현대 무대 (스타트업·병원·아이돌…) | 큐레이션 목록 + 도메인 사실로 태깅 |

- **스키마 ≠ 내용물.** "왕·검·궁정"(표면)이 아니라 "뺏을 권좌·밝혀질 살인"(옮겨지는 조건)만 뽑음.
- 뼈대·세팅을 **같은 25칸으로 라벨링** → 컴퓨터가 겹침을 세서 매칭 가능. (LLM이 채우고 사람이 검수하는 양식)

## 파이프라인
```
빌드(1회, LLM)   WikiPlots → 뼈대표   ·   큐레이션 → 세팅표   (둘 다 스키마로 태깅, 정적 파일)
런타임(코드+LLM) 세팅 선택 → 매칭(요구⊆보유 + 집거리 + 빈도) → 융합(LLM) → 피칭 패킷
```
- **매칭 = 결정적 산수** (집합 겹침 세기). 취향 0, 재현됨.
- **융합 = LLM** 이 뼈대의 역할·턴을 세팅 재료로 이식 (창작).
- **출력 = 피칭 패킷**: 프리미스 · comp("X meets Y") · 로그라인 · 영수증(검증·집거리·충족).

## 왜 데이터인가
- **스키마·뼈대는 도출** — 내 주장이 아니라 실제 이야기가 요구한 조건 (파일럿에서 내 직관 편향 2건 교정·7건 누락 발견).
- **값어치 = "이 조합이 진짜 덜 쓰였다"는 영수증** — GPT는 빈번한 것으로 압축돼 *부재*를 못 셈. 우리는 캐논을 세서 조준.
- **조준 = MAYA** — 제일 빈 칸(❌)이 아니라 *검증된 뼈대(빈도 高) × 안 온 세팅(집거리 멂)* = "같은데 다른".

## 리서치 검증 (2026-08)
- "신선하되 익숙(MAYA)"이 할리우드·출판·웹소설 **시장 중심논리**. 진짜 페인 = **상업 관문**(투고·피칭·공모전).
- 차별점 = **포화/신선도 영수증** (트렌드트래커·태그·비평AI 다 있어도 이건 아무도 안 함).
- 고전×현대는 상업 검증됨 (리텔링 붐 · "Setting Update" 트로프 · Modern AU · Lore Olympus).
