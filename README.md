# classic-bones-modern-fusion

> 수백 년 검증된 **고전 이야기의 뼈대**를, 아직 아무도 안 넣어본 **현대 세팅**에 이식해 —
> 신선하되 말 되는 이야기 프리미스를, **"진짜 덜 쓰였다"는 실데이터 영수증**과 함께 뽑아준다.

design-explosion의 **스토리판**. "AI가 이야기를 쓴다"가 아니라, **수만 편의 실제 이야기를 세어** 뭐가 닳도록 쓰였고(클리셰) 뭐가 신선한지(빈틈)를 짚어주는 **분석 도구**. 산출 형태 = **Claude Code 스킬 + 배포 아티팩트 쇼케이스**(무서버).

---

## 핵심 원리 — LLM이 아니라 "장부(census)"가 값어치
1. **읽기(LLM)**: 이야기를 읽고 트로프·구조 태깅 (센서)
2. **세기(산수)**: 트로프 공기(共起)를 세서 `관측 vs 기대` 장부 → **GPT가 못 하는 유일한 것**(GPT는 빈번한 것으로 압축돼 *부재·꼬리*를 잃음)
3. **쓰기(LLM)**: 장부가 짚은 빈칸에 프리미스 생성 (근데 데이터가 조준)

→ 프리미스는 싸다. **아무도 못 주는 값어치 = "이 조합이 진짜 덜 쓰였다"는 믿을 만한 영수증.** census 신뢰도가 제품 전부.

## 조준 = MAYA (제일 빈 칸 ❌ → 검증된 옆동네 붙은 신선함 ✅)
`freshness(우연보다 덜 나옴) × reachability(각 재료는 옆동네에선 검증됨=comps)`.
죽은 칸(marginal≈0) 자동 탈락 + 클리셰(over-told) 탈락. = 업계의 "같은데 다른(same but different)"을 산수로.

## 융합 3층 — 뼈대 × 스키마 × 세팅
- **뼈대**(예: 햄릿 = 엔진`찬탈복수` + 역할5 + 핵심턴5): 캐논에서 추출한 고정 템플릿. 빈도 = 검증도.
- **스키마**(~25 구조속성): 뼈대의 *요구* ↔ 세팅의 *보유* 를 재는 공통 좌표계. **매칭 = 순수 집합연산(요구 ⊆ 보유), 결정적·감사가능.**
- **세팅**(예: 스타트업): 뼈대 슬롯을 채울 현대 재료(CEO·이사회·지분).

## 출력 = 피칭 패킷 (페인이 "포지셔닝 관문"에 있으니까)
```
프리미스 · comp("X meets Y") · 로그라인 · 영수증(실측/기대) · 뼈대(빈도)
```

## 아키텍처 — 빌드 1회(비쌈) + 런타임(쌈)
- **빌드(LLM, 1회)**: 뼈대표·세팅표를 스키마로 태깅 → **정적 파일**로 얼림
- **런타임(코드)**: 표 조회 + 집합연산 매칭 → LLM은 최종 융합만. **서버·API 불필요.**
- 표면: **스킬**(라이브 엔진, 세션 내 공짜) + **아티팩트**(정적 쇼케이스, 링크 공유)

- **차별점 = 포화/신선도 영수증** — 트렌드트래커·태그·비평AI 다 있어도 이건 아무도 안 함
- 고전×현대는 상업 검증됨(리텔링 붐·"Setting Update" 트로프·Lore Olympus 1.7B뷰·AO3 Modern AU)

## 빌드 계획
1. **속성 스키마 확정**(~25) — 통제 레버
2. **뼈대표 빌드** (WikiPlots→{엔진·역할·턴·요구속성}+군집+빈도) → 정적
3. **세팅표 빌드** (현대 세팅 큐레이션+보유속성 태깅) → 정적
4. **매칭 엔진** (집합연산+집거리+빈도, 결정적)
5. **융합+패킷** (1등만 LLM → 프리미스·comp·로그라인·영수증)
