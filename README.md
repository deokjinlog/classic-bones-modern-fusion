# classic-bones-modern-fusion

> **수백 년 검증된 고전 이야기의 뼈대**를, 아직 아무도 안 넣어본 **현대 세팅**에 이식해 —
> 신선하되 말 되는 이야기 프리미스를 **"진짜 덜 쓰였다"는 실데이터 영수증**과 함께 뽑아준다.

design-explosion의 **스토리판**. "AI가 이야기를 대신 쓴다"가 아니라, 실제 이야기 **11만 편을 세어서** 조준하는 분석 도구.
산출물 = **Claude Code 스킬 + 배포 아티팩트 쇼케이스** (무서버·무API).

## 한눈에 — 뭘 만드는가

작가가 세팅 하나(예: `스타트업`)만 던지면, 이런 **피칭 패킷**이 나온다:

```
프리미스 : 쫓겨난 창업자의 후계자가, 아버지를 몰아낸 공동창업자의 회계부정을
           유출 로그로 알아채지만 — 폭로하면 회사가 죽어 망설이다 파국으로 치닫는다.
comp     : 햄릿 meets 실리콘밸리
로그라인  : 회사를 죽이지 않고 복수할 방법을 찾던 후계자의 망설임이, 결국 모두를 무너뜨린다.
영수증   : 뼈대 340편 검증 · 궁정→스타트업 집거리 멂(신선) · 요구 4/4 충족(말 됨)
```

> **"햄릿을 스타트업에 이식했다."** 수백 년 검증된 구조 위에서 시작하니 백지보다 낫고,
> 아무도 안 해본 조합이라 신선하고, **왜 신선한지 숫자로 증명**된다.

## 어떻게 — 3층 구조

| 층 | 뭐냐 | 어디서 |
|---|---|---|
| **뼈대 (skeleton)** | 이야기의 뼈 = 엔진·역할·턴 (찬탈복수 = 햄릿형) | WikiPlots 플롯에서 추출 |
| **스키마 (schema)** | 뼈대가 *요구하는 조건*의 공통 어휘 (~25칸) | 실제 이야기 요구조건을 **도출** |
| **세팅 (setting)** | 이식할 현대 무대 (스타트업·병원·아이돌…) | 큐레이션 + 도메인 사실로 태깅 |

**스키마는 "내용물"이 아니라 "조건"이다.** `왕·검·궁정`(표면, 안 옮겨짐)이 아니라 `뺏을 권좌·밝혀질 살인`(옮겨지는 조건)만 뽑는다. 뼈대·세팅을 **같은 25칸으로 라벨링**하니 컴퓨터가 겹침을 세서 매칭할 수 있다.

## 파이프라인

```
빌드(1회)  WikiPlots ─▶ 뼈대표      큐레이션 ─▶ 세팅표      (둘 다 스키마로 태깅 · 정적 파일)
────────────────────────────────────────────────────────────────────────
런타임     세팅 선택 ─▶ 매칭 ─▶ 융합 ─▶ 피칭 패킷
                       (코드)   (LLM)
```

- **매칭 = 결정적 산수.** `요구 ⊆ 보유` + 집거리(신선) + 빈도(검증) → 순위. 취향 0, 재현됨, 사람이 검수 가능.
- **융합 = LLM.** 뼈대의 역할·턴을 세팅 재료로 이식(창작). 예: `[죽은 권력자]→쫓겨난 CEO`, `[찬탈자]→이사회 쿠데타 공동창업자`.

## 왜 데이터인가 — GPT가 못 하는 한 가지

GPT에 "신선한 스타트업 이야기 줘" 하면 **제일 시끄러운 클리셰로 회귀**한다 — 학습을 빈번한 것으로 압축해 *부재*를 잃기 때문. 이 도구는 실제 캐논을 **세어서** "이 조합이 진짜 덜 쓰였다"를 증명한다. **값어치는 프리미스가 아니라 영수증**이다.

## 근거 — 시장이 실제로 원하는 것 (리서치 2026-08)

- **"신선하되 익숙(MAYA)"**이 할리우드·출판·웹소설 셋 다의 시장 중심논리 (*"같은데 다른"*).
- 진짜 페인은 **상업 관문**(투고·피칭·공모전)이지 아이디어 생성이 아님.
- **차별점 = 포화/신선도 영수증** — 트렌드트래커·태그·비평AI 다 있어도 이건 아무도 안 함.
- 고전×현대는 이미 상업 검증됨: 리텔링 붐 · TVTropes **"Setting Update"** · Modern AU · *Lore Olympus*(1.7B뷰).
