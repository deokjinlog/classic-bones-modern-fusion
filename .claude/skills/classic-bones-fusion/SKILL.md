# classic-bones-fusion

**검증된 고전 뼈대 × 아직 아무도 안 넣어본 현대 세팅 = 신선한 프리미스.**
매칭은 결정적(코드·취향 0), 융합만 창작(LLM). 가치는 프리미스가 아니라 **근거**(왜 신선한지 숫자) + **깊이**(고전을 비트는 반전).

## 언제 쓰나
사용자가 현대 세팅(스타트업·병원·아이돌…)이나 고전 뼈대를 주고 "이걸로 이야기/프리미스 뽑아줘", "이 세팅에 맞는 고전 구조", "○○을 우주기업만큼 깊게" 할 때.

## 실행 — 5단계

### ① 세팅 확정 (가이드된 자유)
- `data/settings.json` 메뉴에서 고르거나, 사용자가 **자유 입력**.
- 자유 입력이면 → `docs/schema.md`의 **하드게이트 코드(G1~G21)** 로 그 세팅의 *보유 조건*을 태깅. 힌트: 같은 도메인의 기존 세팅이 있으면 그 `affords`를 상속(병원≈종합병원, 배달≈긱이코노미). 사람 검수 가능하게.

### ② 매칭 (결정적·코드)
메뉴 세팅이면 `python3 src/match.py <세팅키>`. 자유 세팅이면 손으로: 각 뼈대 `req` ⊆ 세팅 `보유` 인지 세고, **점수 = 신선도(1−modern_done) × 검증도(proven = freq + 8×canon_freq)**. 완전 적합만 후보, 점수순. 1등만 융합.

### ③ 근거 수집 (숫자 3종)
- **검증** `proven = 빈도 + 캐논×8`, 전체 뼈대 중 순위.
- **실측 census** — `data/census.json`에서 이 세팅 도메인이 실제 이야기(WikiPlots 11만편) 몇 편·희소도 몇 위. 없으면 `python3 src/census.py`.
- **양립** — 요구 n/n 충족(어떤 G코드).

### ④ 융합 = 6레버로 깊게 (창작·LLM)
뼈대의 `roles`·`turns`를 세팅 재료로 1:1 매핑하되, **얕게 멈추지 말 것.** 한 줄 반전은 설명이지 경험이 아니다. 6레버 전부 적용:

1. **하나를 끝까지** — 개요가 아니라 읽었을 때 몰입되게.
2. **재해석 반전(가장 중요)** — 반전은 요약이 아니라 **①번 비트를 다시 읽게** 만들어야 한다. (예: 우주기업 — 화물을 열자 *자기 얼굴* → 항로의 잔해·사이렌이 전부 먼저 죽은 자기들로 재해석됨.)
3. **장면·대사로** — "배신당한다"가 아니라 그 배신이 터지는 장면 한 컷.
4. **인과** — 비트를 "그리고 나서"가 아니라 "~때문에 / 그래서"로 연결. 우연·편의로 풀지 말 것.
5. **톤 지정** — 뼈대에 맞는 결(서늘/실존/누아르/따뜻). ⚠️ 반전이 매번 "적=자기"로 수렴하지 않게 — 외부의 적·구원·관계형도 섞을 것.
6. **근거 접지** — 각 반전이 뼈대의 어느 turn을 비트는지 의식하고, ③의 census 숫자로 신선도를 뒷받침.

**표면은 버리고 구조만 이식.** 과포화 트로프는 피함.

### ⑤ 출력 = 깊은 피칭 패킷
`data/premises.json`의 필드 스키마 그대로 (기존 5개 완성 사례 = **아이돌기획사·우주기업·AI연구소·코인판·셰어하우스**가 품질 기준선):
```
프리미스(p) : 3~4문장, 구체적으로. 반전의 씨앗을 심되 터뜨리진 않음.
로그라인(l) : 한 문장 후크.
comp(c)    : <뼈대 대표작 or 톤 레퍼런스> meets <세팅>
인물(rm)   : 각 role → 세팅 인물 (1:1)
전개(a)    : 뼈대 turns를 세팅 사건 5비트로
훅(hk)     : 이 세팅만의 신선한 진입점 한 줄
반전(tw)   : ①을 재해석시키는 비틀기 (레버 2)
주제(th)   : 이 이야기가 던지는 질문
욕망(wn)   : 겉 목표 vs 진짜 필요 (want vs need)
근거       : 검증(proven 분해·순위) · 실측(census N편·희소도) · 양립(n/n) · 순위
```
- 34세팅 중 하나면 `data/premises.json`의 해당 엔트리를 이 깊이로 갱신하고 `python3 src/gen_explorer.py && python3 src/build_pages.py` 재생성.
- (선택) `exhibits/`에 웹툰 스타일 정적 HTML(6컷 시네마틱 SVG 장면 + 근거 섹션). 작화는 `src/render_art.py`(무료 Pollinations) — 픽셀 정밀도엔 한계, 구도·빛으로 승부.

## 원칙
1. **매칭은 취향 0** — 요구⊆보유 겹침 세기. 재현·검수 가능. 도구가 고른 1등을 존중(내가 넘겨짚지 말 것 — 예: AI연구소는 프랑켄슈타인이 아니라 괴물퇴치가 1등).
2. **융합만 창작** — 뼈대가 구조를 고정하니 통제된 창의.
3. **근거 필수** — 신선·검증·양립 숫자 없이 프리미스만 내지 않음. 정직: census는 영어 코퍼스라 상대 순위로 해석.
4. **깊이 필수** — 훅·반전·주제·욕망 없이 개요만 내면 "만들다 만" 것. 반전은 반드시 앞을 재해석시킬 것.
5. **뻔하면 자동 후순위**(신선도↓), **안 맞으면 near-miss 보강 제안**(요구 한 끗 부족 → 그 조건 넣는 법).

## 데이터 파일 (프로젝트 루트 기준)
- `data/skeletons.json` — 뼈대 23종 (req·home·freq·canon_freq·proven)
- `data/settings.json` — 현대 세팅 34종 + 보유 하드게이트 코드
- `data/premises.json` — 세팅별 깊은 피칭 패킷 (p/l/c/a/rm/hk/tw/th/wn) · **품질 기준선**
- `data/census.json` · `src/census.py` — 도메인 실측 신선도
- `docs/schema.md` — 스키마 (하드게이트 21로 매칭)
- `src/match.py` — 결정적 매칭 · `src/gen_explorer.py`·`src/build_pages.py` — 탐색기/페이지 생성
- `src/render_art.py` — 웹툰 작화(무료 Pollinations, 선택)
