# 스토리 구조 스키마 v1 (locked)

뼈대가 **요구하는** 조건 / 세팅이 **보유한** 조건의 공통 어휘.
WikiPlots **명작 56편 + 랜덤 46편** 플롯에서 요구조건을 추출·군집해 도출(내 주장 아님).

**사용법**
- 뼈대엔 *요구 조건*, 세팅엔 *보유 조건*을 이 어휘로 태깅.
- **매칭은 하드게이트로만** (`요구 ⊆ 보유`). **보편 조건은 매칭에서 제외**(거의 모든 세팅에 있어 변별 못 함). **전개 태그는 정렬·성격 표시용**(정적 세계조건이 아니라 사건 모양).

## 도출 근거 & 화해 (랜덤 46 ↔ 캐논 56)
- 프리셋 v0-25의 **84% 지지 유지.**
- **승계·축취(G3): 캐논에서 9/56(~16%)로 확실히 부활** — 햄릿·라이온킹·대부·맥베스·듄·템페스트 등. 랜덤에선 0이었던 건 *현대 랜덤 플롯이 권좌 다툼을 잘 안 다뤄서*지 죽은 게 아님. **"랜덤은 캐논 구조를 과소평가한다"가 실증됨.**
- **귀환할 집(G4): 3–4/56로 완만 부활**(호빗·라이온킹·헨젤과그레텔). ⚠️ 오디세이가 샘플에 잘못 매칭돼 빠져 *과소측정*됨 — 그래서 낮은 빈도에도 캐논-진단적이라 하드게이트 유지.
- 프리셋이 놓친 7개(평판·수사·경제·강압·유사유대·마감·문턱) 모두 확인.
- 캐논이 **새로 4개** 부상(★NEW): 예언·운명 · 위장·이중정체 · 사부·수련 · 두 세계 접촉 — 신화·비극·SF에 흔한데 랜덤이 과소평가.
