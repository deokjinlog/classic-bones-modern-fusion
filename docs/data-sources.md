# 데이터 소스 도시에 — "장르 컨벤션 팩 → 시나리오 → 웹툰"

> **프로젝트 한 줄**: 장르(로판·무협·개그…)를 고르면, 그 장르의 **인기 컨벤션 팩**(아키타입·관계·비트·설정)을 접지해 **시나리오가 쭉쭉** 나오고, 나아가 웹툰 컷까지. design-explosion의 스토리 버전.
> **작성**: 2026-08-03 · 데이터부터 확정하고 기획을 그 위에 얹는다.

---

## 핵심 통찰 — 본문(저작권)이 필요 없다

방향이 **"각색"이 아니라 "오리지널 현대물 생성"**이므로, 저작권 걸린 소설 **본문은 필요 없다.** 필요한 건 **정제된 "신호"**:
- 뭐가 인기냐(장르·상호작용) · 어떤 관계·트로프가 먹히냐(태그) · 플롯이 어떻게 굴러가냐(구조) · 독자가 뭐에 반응하냐(리뷰)
- → 본문 생성은 LLM, 데이터는 "뭐가 먹히나" 접지용. **저작권 회피 + 인기 신호 확보 동시.**

`LLM이 이미 아는 것`(막연한 유머·장르 감)은 안 쌓는다. `LLM이 모르는 것`(정제된 인기 신호·큐레이션한 장르 팩·검증 루브릭)만 쌓는다.

## ⚠️ 라이선스가 조합을 가른다

| 목적 | 데이터 조합 | 이유 |
|---|---|---|
| **포폴·개인·비상업** | ① Goodreads + ② TVTropes+AO3 + ③ WikiPlots + ④ 공개도메인 | 제일 풍부. TVTropes(장르 컨벤션 골드마인) 써도 됨 |
| **상업(서비스·수익)** | ③ **WikiPlots**(→ 장르 팩 직접 추출) + CMU + ④ 공개도메인 + AI-Hub | TVTropes(NC)·본문 저작권 회피. WikiPlots에서 추출한 팩은 **네 IP** |

**상업 안전판 = WikiPlots(CC-BY-SA)에서 장르별 아키타입·관계·비트를 직접 추출** → 그 결과물이 소유권 있는 내 데이터가 됨(TVTropes NC 함정 회피).

## 획득 순서 (docs-rag 스택 재사용)

```
STEP 1  ③ WikiPlots 11.3만 플롯 다운(plots.zip) → 장르 태깅 → 임베딩·인덱싱
        = "이 장르 플롯이 어떻게 굴러가나" 구조 인덱스 (상업 안전, 제일 먼저)
STEP 2  ① Goodreads 메타 다운 → 장르별 인기·리뷰 신호 추출
        = "뭐가 먹히나" 인기 인덱스
STEP 3  ② TVTropes/AO3 태그 → 관계·트로프·아키타입 추출 (포폴이면)
        = 장르 팩의 "관계·트로프" 슬롯
STEP 4  ①②③ 합쳐 장르 팩 1개(예: 로판) 조립 → "팩 → 시나리오" 흐름 실증
```
